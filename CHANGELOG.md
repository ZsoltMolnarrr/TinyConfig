# Changelog

## 4.0.1

- NeoForge manifest now declares the square mod logo with `iconFile` instead of the deprecated `logoFile`, removing the "uses the deprecated `logoFile` property" loading warning on NeoForge 26.2.

## 4.0.0

- Support for the Minecraft 26.x line (26.1, 26.1.1, 26.1.2, 26.2) — one jar serves all of them.
- Moved to the unobfuscated 26.1+ toolchain (no mappings, no remapping) and Java 25.
